Le trajet d’un site public.

Suivez les échanges déclenchés quand vous ouvrez example.com, avec une adresse IP de démonstration.

Résolveur DNS Navigateur Internet Hébergement
↗ A example.com↙ 192.0.2.42
↗ TLS · ClientHello↙ TLS · ServerHello
↗ GET /↙ 200 OK · text/html

  1. Le résolveur DNS renvoie une adresse IP. Le résultat peut déjà être en cache.

    A example.com → 192.0.2.42

  2. Le navigateur et le serveur négocient une connexion chiffrée. Le navigateur vérifie le certificat du domaine.

    TLS · ClientHello → TLS · ServerHello

  3. Sur la connexion HTTPS, le navigateur demande la page. Le serveur renvoie le HTML, puis le navigateur demande les styles, scripts et images nécessaires.

    GET / → 200 OK · text/html
Nom de domaine
L’adresse que vous enregistrez et renouvelez chez un bureau d’enregistrement.
DNS
Un enregistrement A ou AAAA pointe vers une IP. Un CNAME sert d’alias vers un autre nom.
Hébergement
Le service qui publie les fichiers du site et les envoie au navigateur.
